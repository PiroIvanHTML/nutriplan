# NutriPlan

Piano alimentare settimanale — struttura modulare.

## Struttura

```
index.html                    markup della pagina
assets/css/base.css           stili base + regole di stampa
assets/css/premium.css        stili premium (solo schermo)
assets/js/fullscreen.js       gestione API fullscreen
assets/js/main.js             toggle e grafici (Chart.js)
assets/js/premium-effects.js  animazioni e riflessi progressivi
```

## Sviluppo

Aprire `index.html` in un browser. Nessun build step richiesto.
